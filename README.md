# Sales Tax Calculator API for Make

A Make custom app for using the Sales Tax Calculator API in scenarios.

**Status: scaffold only. This app is not published or ready to install.**

## Planned scope

- Connect with a Sales Tax Calculator API key.
- Add a module to submit a tax request from mapped scenario data.
- Return the API outcome, tax, total, and request ID to later scenario steps.
